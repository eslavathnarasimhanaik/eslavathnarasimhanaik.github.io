DukaanAI — Conversational Retail Ledger

Live Demo ↗ GitHub ↗
🚨 Problem
Small retail shop owners struggle with managing paper inventory logs, credit files, and invoice generation, resulting in manual calculation errors and wasted hours.
🎯 Goal
Develop an easy-to-use conversational interface allowing owners to create invoice records and update client debt files through natural language.
🛠️ Solution
Built a conversational UI mapping natural queries to ledger modifications. Integrated Spring Boot backend acting as JSON command interpreter and parser.
🏗️ Architecture
React ➔ Spring Boot ➔ OpenAI API ➔ MongoDB
✨ Key Features
Natural language command interpretation in JSON mode, automatic invoice PDF creation, real-time inventory adjustments.
⚠️ Challenges
Conversation memory persistence, prompt reliability, and validating ambiguous multi-intent queries.
